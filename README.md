## Inspiration

This website was created as a response to the disappointingly basic original [Superman website](https://www.supermanmovie.net/). Drawing heavy inspiration from the interactive design of the [Lando Norris website](https://landonorris.com/), this project aims to deliver a worthy website for **The Man of Steel**.
